# Developer Guide

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/maximilanoTS/Maxmsi.git
   cd Maxmsi
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

## Architecture
- **Folder Structure**:
  - `/src`: Contains the source code.
  - `/tests`: Contains the test files.
  - `/docs`: Documentation files.

- **Key Components**:
  - **Main Module**: Entry point for the application.
  - **Services**: Business logic to interact with the core functionality.
  - **Controllers**: Handle requests and responses.

## Contribution Guidelines
1. **Fork the repository**: Create a personal copy of the repository.
2. **Create a new branch**: Use descriptive branch names to identify your work.
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes**: Develop and test your changes thoroughly.
4. **Commit your changes**: Follow standard commit message guidelines.
5. **Push to your fork**: 
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Create a pull request**: Submit a pull request with a clear description of your changes.

Thank you for contributing!
